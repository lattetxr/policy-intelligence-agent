# 政策智能分析 Agent 系统（Policy Agent）

> 政治学 / 公共政策垂直领域的智能政策分析智能体 · Vibe Coding 快速原型
> 面向政务实验室项目申报、中小企业政策扶持匹配、政策落地效果研判三大真实业务场景

---

## 1. 项目简介

本项目是一个**政治学垂直领域政策智能 Agent 系统**，以 Vibe Coding 方式快速搭建的政务办公原型。系统将 **政策 PDF 知识库（RAG）** 与 **大语言模型智能体（Agent）** 相结合，实现从「政策文档解析 → 企业政策匹配 → 申报材料标准化 → 落地效果评估」的完整业务闭环，为政务项目申报、中小企业政策服务、政策评估研判提供一站式智能分析能力。

项目以简洁政务风 Web 界面交付，6 大功能页面逻辑闭环，可从头到尾连贯演示基础能力与三轮迭代新增功能，适配求职作品集展示。

---

## 2. 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | **Streamlit** | 政务风 Web UI，卡片分块布局，无需前后端分离 |
| Agent 编排 | **LangGraph** | 有向图编排「检索 → 分析 → 回答」多轮工具调用（上限 4 轮） |
| 多模型接入 | **AISuite** | 统一调用 OpenAI / Anthropic / DashScope 等多家大模型 |
| 大模型 | **通义千问 Qwen-Max** | DashScope OpenAI 兼容接口直连（含 JSON 结构化模式） |
| 本地检索 RAG | **ChromaDB + fastembed** | 本地向量库，默认启用零依赖字符 n-gram 兜底嵌入，完全离线可用 |
| PDF 解析 | **pdfplumber** | 政策 PDF → 文本切块 → 向量化入库 |
| 文档导出 | **python-docx / fpdf2 / openpyxl** | 评估报告导出 Word / PDF / Excel / Markdown 多格式 |
| 开发方式 | **OpenCode** | Vibe Coding 对话式开发，迭代式交付 |

## 3. 完整功能清单

### 基础模块
- **📚 政策知识库管理**
  - 批量上传 / 解析政策 PDF，文本切块向量化入库
  - 政策要素智能提取：申报门槛、适用主体、量化阈值、补贴标准、约束条款
  - 文档管理表格（文件名 / 大小 / 入库状态）+ 向量库运行状态看板

### 迭代 1：政策申报材料标准化
- **📋 申报材料标准化模块**
  - 自动梳理申报全链路流程（申报准备 → 线上填报 → 材料递交 → 初审 → 专家评审 → 公示拨付）
  - 输出标准化申报材料清单（材料名称 / 格式要求 / 内容要点 / 提交节点）
  - 审核易错点与质量管控清单汇总
  - 一键导出 Markdown / Excel 申报材料台账

### 迭代 2：政企需求智能匹配
- **🤝 政企需求智能匹配模块**
  - 录入中小企业经营现状 + 发展痛点 + 政策诉求
  - 自动检索本地政策库扶持条目，逐政策匹配度打分（0-100）
  - 输出匹配总分、适配政策列表（政策名称 / 匹配度 / 适配条款 / 落地建议）
  - 原文溯源查看，所有结论可回溯政策原文，规避大模型幻觉

### 迭代 3：政策落地评估报告自动生成
- **📊 政策落地评估模块**
  - 关联数据调取：自动绑定往期政企匹配数据与扶持政策全集
  - 政策条文 + 适用人群 + 落地约束 + 企业反馈四维度输入
  - 结构化生成规范政务评估报告（①总体概况 ②实施成效 ③难点制约 ④迭代对策）
  - 报告导出 Markdown / Word / Excel 多格式，自动归档至 output 目录

### 其他能力
- **🏠 首页仪表盘**：核心数据统计（入库政策 / 匹配次数 / 材料清单 / 评估报告）+ 快捷功能入口
- **⚙️ 系统参数与安全配置**：模型推理参数、API 密钥安全管理（不展示明文）、缓存清理 / 日志查看 / 项目重置
- **A/B 多模型对比**：同一问题并行调用两个模型，输出对比分析

## 4. 本地运行步骤

### 环境要求
- macOS / Linux / Windows（本文以 macOS ARM64 为例）
- Python 3.11+
- 通义千问 API Key（DashScope）或其他模型 Key

### 步骤一：克隆项目并创建虚拟环境
```bash
cd policy-agent
python3 -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
```

### 步骤二：安装依赖
```bash
pip install -r requirements.txt
# 核心依赖：streamlit aisuite langgraph pdfplumber chromadb fastembed \
#           openai python-dotenv pydantic loguru pandas openpyxl python-docx fpdf2
```

### 步骤三：配置 API 密钥
在项目根目录创建 `.env` 文件：
```
DASHSCOPE_API_KEY=你的通义千问Key
# OPENAI_API_KEY=可选
# ANTHROPIC_API_KEY=可选
```

### 步骤四：放入政策文档
将政策 PDF 放入 `policy_docs/` 目录（或直接上传，示例文件已含光谷中小企业技术创新专项资金申报指南）。

### 步骤五：启动 Web 应用
```bash
# 方式一（推荐，激活 venv 后启动）
source venv/bin/activate
streamlit run policy_agent.py

# 方式二（脚本内置 venv 自动引导，任意 Python 均可）
python3 policy_agent.py
```
浏览器打开 http://localhost:8501，按首页「快捷功能入口」即可走通全流程。

## 5. 创新亮点

1. **文科政策场景的垂直智能体**
   - 突破「AI = 代码」的固有印象，将大模型 Agent 应用于政治学 / 公共政策分析
   - 输出直接贴合政务公文规范（评估报告、申报台账、审核清单），非通用聊天回复
   - 中文政策语义处理：BGE 中文嵌入 + 本地 RAG，离线可用、数据不出沙盒

2. **多模型对比与结构化输出**
   - A/B 双模型同题对比，供决策者选择更优模型
   - 通义千问 JSON 结构化模式，评估报告/材料台账输出为规范结构化字段，可直接二次加工

3. **政企匹配全链路可溯源**
   - 匹配度打分 → 适配政策条目 → 原文片段溯源，分析结论均回溯政策原文，规避大模型幻觉

4. **工程化细节**
   - 三模块流水线端到端真实调用验证通过
   - 多格式文档导出（Word / Excel / Markdown / PDF）+ 自动归档
   - 政务蓝视觉规范、卡片分块布局、异常场景友好提示

## 6. 后续拓展规划

- **政策语义深度检索**：升级 bge-large-zh + 混合检索（BM25 + 向量），提升多政策库场景召回精度
- **多 Agent 协作**：引入规划 / 检索 / 撰写分离的 Multi-Agent 架构，支持批量政策批量评估
- **企业画像沉淀**：历史匹配结果沉淀为企业画像库，支持政策推送与申报日历提醒
- **评估指标量化**：评估报告接入落地率 / 满意度 / 资金到位周期等量化指标计算
- **报表自动化**：周报 / 月报自动聚合，输出政务数据看板
- **安全与权限**：支持多角色登录、审计日志、密钥加密存储（Keyring）
