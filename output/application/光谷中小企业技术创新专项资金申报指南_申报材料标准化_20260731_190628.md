# 光谷中小企业技术创新专项资金申报指南 · 申报材料标准化方案

- 生成时间：2026-07-31 19:06:28　模型：tongyi

## 一、申报全链路流程

| 执行环节 | 关键内容 | 责任主体 | 预计周期 |
| --- | --- | --- | --- |
| 申报准备 | 企业根据指南要求，准备相关材料 | 申报企业 | 1-2周 |
| 线上填报 | 通过线上系统提交申请表及相关材料 | 申报企业 | 1-3天 |
| 材料递交 | 在线上系统中上传所有申报材料 | 申报企业 | 1-3天 |
| 初审 | 审核部门对提交的材料进行初步审查 | 审核部门 | 1-2周 |
| 复审/专家评审 | 组织专家对初审通过的项目进行评审 | 评审委员会 | 2-4周 |
| 公示 | 评审结果在官方网站上公示7天 | 审核部门 | 7天 |
| 拨付立项 | 公示无异议后，正式立项并拨付资金 | 审核部门 | 1-2周 |

## 二、材料规范要点

1. 所有材料需加盖公章
2. 财务审计报告需由有资质的第三方机构出具
3. 知识产权证明需提供有效期内的证书复印件
4. 申请表需按要求填写完整，不得有遗漏

## 三、审核易错点

1. 年营业收入低于2000万元，建议提前核对财务报表数据
2. 研发费用占销售收入比例不足3%，建议重新核算研发投入
3. 知识产权数量不足5项，建议补充相关证明材料
4. 同一项目重复申报其他同级专项资金，建议避免多头申报

## 四、标准化申报材料清单

| 材料名称 | 格式要求 | 内容要点 | 提交节点/注意事项 |
| --- | --- | --- | --- |
| 申请表 | PDF | 企业基本信息、项目概况、资金需求等 | 线上填报时上传 |
| 财务审计报告 | PDF | 最近两年的财务报表及审计意见 | 线上填报时上传 |
| 知识产权证明 | PDF | 有效期内的知识产权证书复印件 | 线上填报时上传 |
| 合作协议 | PDF | 与合作单位签订的技术开发合同或协议 | 如有合作单位，线上填报时上传 |
| 承诺书 | PDF | 企业承诺专款专用及配套自筹资金的承诺书 | 线上填报时上传 |

## 五、质量管控清单

1. 确保所有材料齐全且符合格式要求
2. 核实财务数据的真实性和准确性
3. 检查知识产权的有效性
4. 确认项目未重复申报其他同级专项资金
5. 确保承诺书内容完整且已盖章
